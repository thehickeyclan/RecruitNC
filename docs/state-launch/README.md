# Per-state accounting files

`<STATE>-accounted.json` names each exception the go / no-go gates in `scripts/state-readiness.ts` accept: a placer without a profile (with the reason), a class year left unresolved, a verified pre-freshman varsity result. Format and rules: `docs/STATE-LAUNCH-CHECKLIST.md`. An exception without a reason Matt would accept does not belong here; fix the data instead.
